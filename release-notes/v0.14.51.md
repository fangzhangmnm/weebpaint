## Thumbnails rebuild once; your "Revert" history comes along

WeebPaint's own small database on this device has a new, app-specific name, so it can no longer collide
with another page's storage. The first time you open this version, the "Revert" snapshots move over to the
new database by themselves, in the background, after your painting has opened. Gallery thumbnails are not
moved — they are rebuilt the next time the gallery shows them. Nothing about your paintings themselves
changes.

## The itch.io and downloaded versions say what they can't do

On itch.io and in the downloaded single file, connecting OneDrive is not possible (Microsoft sign-in can't
return there). The menu item is now greyed out and points to weebpaint.com instead of looking clickable and
failing, and a one-line note at start says the same. Everything else works as before; saving downloads an
.ora file.

## Remember the password in the downloaded version

The downloaded single file now offers "Remember on this device" too. The checkbox says plainly that other
pages you open by double-clicking on the same computer can also reach that key — tick it only if that is
fine for you. The itch.io version still does not remember passwords.

## Renaming when the cloud copy doesn't match

If you rename a painting that has edits not yet uploaded, and the cloud copy was changed on another device
(or this device can't tell which cloud version it came from), WeebPaint now asks: move the old cloud copy
to the trash (it can be restored), keep both, or cancel the rename.

## Untested browsers

If a browser won't let WeebPaint store anything (for example Safari opening the downloaded file), a note
says so at start: settings and crash backups won't survive closing the page, so save your work as files —
and there is a link to report problems.
