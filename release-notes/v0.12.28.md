## Pen pressure on Windows — read this if your lines come out flat

Browsers can only receive pen pressure through **Windows Ink**. If your tablet driver is set up for
WinTab only, the browser just sees a plain mouse — constant pressure, constant line width — and there
is no web API that lets an app tell you that directly.

This build adds a self-diagnosis. When WeebPaint sees evidence that pressure is missing, it shows a
one-time notice — *"No pressure? Please enable Windows Ink in your tablet driver"* — with a **Details**
button that opens the new built-in help page carrying the full fix.

**The fix, in short:**

1. Open your tablet driver panel (Huion / XP-Pen / Wacom) and enable **Windows Ink** in its pen settings.
2. Close every browser window, then reopen it and come back to WeebPaint.
3. Try a pressure-sensitive brush — brushes whose names say "fixed" ignore pressure by design.

Enabling Windows Ink does **not** break Clip Studio Paint or Photoshop; they can keep using WinTab. If
Windows Ink brings back the ink ripple or the long-press right-click menu, turn those off in Windows
Settings → Pen & Windows Ink.
