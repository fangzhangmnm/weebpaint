# 便条（来自 CatsUp 会话 2026-10-30）：一键藏起所有窗（四指轻点，Procreate 同款）

> created 20261030 by Claude Opus 5.5（CatsUp 侧会话代 user 投递）

- **user 原话**（CatsUp 会话，聊浮窗多了会挤）：「我其实想的是只能有一个浮窗，但是可能不合理，weebpaint我也开着图层和色彩」「以后可以加一个「一键藏起所有窗」，像 Procreate 四指轻点全屏。 现在就可以做。我还不知道有这个功能，然后weebpaint也提交工单让它做」。
- **要什么**：一个开关，把开着的浮窗（图层、色彩……）一起藏起来，再来一次原样回来。手指 = 四指轻点（Procreate：两指撤销、三指重做、四指全屏）；键盘给一个键。
- **CatsUp 的做法（v0.18.6，可以照抄）**：`src/app/ui/hide-windows.ts`（30 行）。
  - 藏 = 页面根上加一个标记，样式把浮窗藏掉；窗口自己的开关状态一点不动，再来一次原样回来，不用记谁开着。
  - 工具栏照旧在（Photoshop Tab 那种「藏面板留工具」，照样能画）。
  - 藏着时点开窗的钮：第一下只把窗叫回来，不然会点了没反应、或者把藏着的那扇关掉。
  - 本来就没有开着的窗：不进藏的状态，只说一句。
  - 多指轻点那段在 `src/app/gestures.ts`：原来三指及以上都算重做，改成三指重做、四指藏窗。WeebPaint 的多指 tap 是 CatsUp 抄的源头，坑一样（掌触门、幽灵指针）。
  - 键：CatsUp 用 `\`（Tab / Shift+Tab 已经有用了）；WeebPaint 按自己的键表定。
- **优先级**：todo，user 没排期；WeebPaint 按自己的账走。
