# 便条（来自 CatsUp 会话 2026-10-29）：☰「新建 / 打开」下面单独放一个「导入」

> created 20261029 by Claude Opus 5.5（CatsUp 侧会话代 user 投递）

- **user 原话**（CatsUp 会话）：「新建与打开改名新建/打开/导入，或者导入单独放一个？等等。导入必须单独放，weebpaint里面新建与打开里面是没有导入的导入是在图层里面相当于我们未来的hierarchy，不过考虑到我们的工作习惯。我建议是新建打开下面专门放一个导入 然后给weebpaint收件箱todo list说他们的新建打开下面也放一个导入」；随后「所以新建打开还是用加号。导入用导入符号」。
- **要什么**：WeebPaint 的 ☰「新建 / 打开」那一行下面，单独加一行「导入」（导入图标）。现在 WeebPaint 的导入住在图层面板里（= CatsUp 将来的层级 / hierarchy 那个位置），user 的意思是那里照留，☰ 文件页再给一个顺手的入口（工作习惯：找文件进来的东西先去 ☰ 文件页）。
- **CatsUp 这边的样子**（v0.17.41）：☰ 文件页 = 图库 → 新建 / 打开…（加号图标）→ 导入…（导入图标，点开小弹层：导入 glb / 导入 OBJ）→ 导出与另存… → 锁上 …
- **优先级**：todo，user 没排期；WeebPaint 侧按自己的账走（家族菜单顺序 F-81 那张表要不要跟着加一行，看完一起定）。
