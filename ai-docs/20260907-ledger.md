## 用法（AI 必读；`test/ledger-lint.test.mjs` 机械执法）

- **一行 = `- #编号 [S|M|L|?] 一句话 · 状态 · 登记日 · → 指针 · 触发：词`**。S/M/L = 体量（S = 一个 session 顺手、L = 一轮 grill 或一个纪元）。**编号跨节不变、永不复用**——reshuffle = 剪贴整行，编号跟着走；开新 agent 时丢「本文件 + #编号」。lint 守：编号唯一、`next-id` 大于最大编号、状态词在集内、指针文件存在、一句话里的 `#n` 引用不指空、单行 ≤ 260 字符。
- **详情不进本文**：一句话装不下就去开 doc（handoff / grill 稿 / 便条 / ADR）再指过来；user 原话指 journal（AI 只读）。
- **状态词**：`待做`（拍板可开工）· `进行中` · `待拍板`（要 user 一句话）· `待看`（要 user 过目）· `已问`（AI 问过一次，**不再催**）· `等数据`（要复现 / 真机 / 上手）· `wishlist`（user 点名要，不排期）· `远景`（脑洞，触发词命中就翻）· `park`（明确不做，记着只为不再提）· `冲突` · `done`。
- **节 = 优先级桶**，条目在桶间挪不改编号。做完把状态改 `done <版本>`；纪元收口时把 done 行整批删掉（git 有史，索引保持薄）。
- **短命反馈不进本文**：本轮 grill 稿 / feedback thread 里消化，轮次收口时只把残余提成一行。
- **不催纪律**：`已问` / `待拍板` 行 AI 不在聊天里再提（user 2026-09-06「别催我…需要时间积淀」）；user 问「欠着什么」时把 §2 整节抄给 ta。
- **冲突纪律**：两句原话打架不由 AI 裁——登记进 §3，施工碰到时把两句原话摆出来问。
- **触发词纪律**：user 一提到 §7 某行的触发词，先翻那行的详情再动手（user：「等哪天我说我们需要做星星的时候，你应该需要会想起这个脑洞」）。
- **便条箱** `ai-docs/inbox/` 每条便条必须在 §10 有对应行；便条末尾签「已阅」，不删。
- **老账**：0828 总账 §3 的 28 条已于 2026-09-07 逐条对账（绝大多数 done），残余已提成本表各行；再考古去 `ai-docs/20260828-localfile-knight-completion-ledger.md` / `ai-docs/20260830-v012-epoch-backlog-and-parked.md` / `ai-docs/20260528-backlog.md`（旧格式，只读不续写）。
